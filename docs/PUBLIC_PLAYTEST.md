# Guía de playtest público

## Invitación breve

> El Pueblo Oculto es una beta experimental para 3–6 personas. Cada jugador necesita su propio navegador. El servidor gratuito puede tardar cerca de un minuto en despertar. Las salas no se guardan si el servidor se reinicia. No compartas capturas que revelen roles, pistas, votos, mensajes o el código de la sala.

Comparte únicamente la URL HTTPS real verificada en `PRODUCTION_CHECKLIST.md`; no uses una URL supuesta.

## Antes de empezar

1. El anfitrión abre la URL y espera a que aparezca **Conectado**.
2. Si se muestra “El servidor puede estar despertando”, espera hasta un minuto y usa **Reintentar** una vez si fuera necesario.
3. Cada persona usa su propio teléfono o navegador y protege su pantalla.
4. El anfitrión crea la sala y comparte su código solo con el grupo por un canal privado.
5. Si el servicio se reinicia o se vuelve a desplegar, creen una sala nueva.

## Qué probar

- Una partida completa y **Volver a jugar**.
- Una recarga durante espera o conversación.
- Una desconexión breve y recuperación.
- Legibilidad con teclado móvil, sonido opcional y navegación por teclado.
- Claridad de historia, pistas, conversación, votación y resultado.

## Reportar un problema

Abre **Acerca del prototipo > Copiar reporte técnico seguro**. El texto incluye solo versión, etapa, navegador, fecha y el último código de error público. Añade una descripción general de lo que intentabas hacer.

No incluyas códigos de sala, nombres, mensajes, roles, pistas, votos, capturas privadas, datos de sesión ni tokens. Si el problema revela información privada o impide terminar la partida, detén la sesión y avisa al responsable por el canal privado acordado.
